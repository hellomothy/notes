# What is Git and GitHub?
Git is a distributed version control system (DVCS) that manages your projects. Often times projects have many different versions and managing them can be cumbersome. Git tracks these changes, project histories, and the users who made those changes through "snapshots" that capture the current state of the project. Git can be used locally to manage projects on your local drive. What makes Git different from other VCSs is that the project is not centralized, meaning that everyone has a copy of the project. That means you are able to work on it without internet and collaborate easily.
GitHub is a server that makes sharing these projects simple, accessible, and free. It is built utilizing the Git framework for shared projects.
### Sidenote on Terminology
Projects are called ==repositories==. They store all the files, directories, and changes within them. When working locally, it is called a ==local repository==. When working on GitHub or any other server-hosted project, it is called a ==remote repository==.
